### Computer Vision Projects

A collection of five projects completed during a five-week elective computer vision programme at Pan-Atlantic University.

The projects provided practical experience with image processing and computer vision, progressing from basic image operations to edge detection and detection using pretrained models.

#### Projects
Week 1 — Image Loading

Practised loading and working with images in Python.

Week 2 — Image Transformations

Implemented basic image transformations, including grayscale conversion and colour inversion.

Week 3 — Image Transformations

Explored additional image transformations and their effects on image appearance.

Week 4 — Edge Detection

Worked with edge detection techniques to identify boundaries and features in images.

Week 5 — Detection

Explored detection using computer vision tools and a pretrained model.

#### Technologies
Python
OpenCV
YOLO / OpenCV DNN
About
